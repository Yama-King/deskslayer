# 0006. PlayStyleProfile 演算法：採用 Welford's Online Algorithm

## 狀態

已採用

## 背景

`PlayStyleAnalyzer` 負責依玩家的按鍵節奏與輕重攻擊傾向，輸出當日與累積雙軌的風格分數。此模組於專案中期完成程式編寫後，直到分享卡系統開發階段才首次被實際掛載到場景中運行。實際運行後發現，該模組自完成以來從未被其他任何系統讀取或驗證過輸出結果，其正確性僅止於通過編譯，未經過實際驗證。

啟動驗證後，確認原始演算法設計存在缺陷，需要進行修正。

## 決策

原始設計採用固定滾動視窗統計最近一段時間的按鍵行為，此做法的缺陷在於統計範圍受限於視窗大小，無法反映完整的遊玩歷程，且視窗越大，記憶體佔用隨之增加。

改採 **Welford's Online Algorithm**，僅以三個純量累加器（樣本數、平均值、平方差累加量）即可線上更新統計量，不需要保存歷史資料本身。此演算法讓風格分數的統計範圍涵蓋玩家完整的 session 歷史，且記憶體佔用不隨時間增長，解決了固定滾動視窗的兩項限制。

## 後果

正面影響：風格分數的統計基礎從「最近一段時間的片段行為」改善為「完整的遊玩歷程」，更符合「分析玩家真實戰鬥風格」的設計初衷；記憶體佔用維持定量，不因遊玩時間拉長而增加負擔。

負面影響：此次修正過程也暴露了一個獨立於演算法本身的風險——模組完成編寫與功能被實際驗證運行，是兩個不同的狀態，中間可能存在相當長的落差期間而未被察覺。這代表僅依賴「規格書標記完成」或「編譯通過」，不足以確保邏輯的正確性，需要額外的驗證機制或流程來縮短「完成」與「驗證」之間的落差。
