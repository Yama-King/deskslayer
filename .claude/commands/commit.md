description: 依照 DeskSlayer 專案慣例整理目前變更並準備 commit
---
請依序執行以下步驟：

1. 執行 `git status` 與 `git diff`（包含未追蹤的新檔案），完整確認目前所有變更。
2. 列出一份清單，每個變更的檔案搭配一句簡短說明，講清楚這個檔案為什麼被改動、對應哪個功能或修正。
3. 依照 Conventional Commits 格式（英文、祈使語氣，例如 feat/fix/refactor/docs），
   建議把這些變更拆分成幾筆語意完整的 commit。拆分原則：
   - 每一筆 commit 要能獨立講清楚「這筆做了什麼、為什麼」，不要把不相關的改動混在同一筆
   - 場景檔案（.unity）如果同時涵蓋多個功能的變動，在 commit 說明中要註明清楚
   - 因為 TextMeshPro 或其他工具自動產生的副作用檔案（例如字型圖集），要在對應那筆 commit 的說明中註明是自動產生的副作用，不是刻意修改
4. 把每筆建議的 commit 訊息完整寫出來（含 subject 與必要的 body），排版成可以直接複製使用的格式。

**在我明確回覆確認這份清單與拆分方式無誤之前，不要執行任何 `git add` 或 `git commit`。**
如果你在檢查變更時發現任何看起來像是我不記得自己做過的修改（例如非我要求的檔案被刪除或還原），
要先停下來明確提出詢問，不要假設這是測試殘留而自行處理。
